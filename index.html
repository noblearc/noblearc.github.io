FAQ

자주 묻는 질문

구매 후 어떻게 프로그램을 받을 수 있나요?
결제 완료 후 이메일로 라이선스 키, 프로그램 다운로드 링크, 사용설명서 링크가 발송됩니다. 라이선스 키는 한 번만 입력하면 이후 자동으로 활성화됩니다. Windows 전용 프로그램입니다.
몇 대의 PC에서 사용할 수 있나요?
각 프로그램당 1대의 PC에서 사용할 수 있습니다. 기기 초기화를 통해 기기를 변경할 수 있습니다.
프로그램을 동시에 사용해도 되나요?
프로그램별로 동시 사용이 가능합니다. 다만 API 키가 중복된 경우 충돌을 막기 위해 순차적으로 사용하시길 권장합니다.
API 비용은 어떻게 되나요?
모든 프로그램의 API 사용료는 이용료와 별도이며 본인 API 키 기준으로 발생합니다. 노블아크와 포스티아는 Google 신규 가입 시 제공되는 $300 무료 크레딧을 활용할 수 있습니다(Google 정책 및 조건 적용). VYNKO의 상품 이미지 → 영상 전환 기능은 무료로 제공해 드립니다.
이용 기간이 끝나면 어떻게 되나요?
이용 기간이 만료되면 프로그램 사용이 중단됩니다. 홈페이지에서 재결제하시면 즉시 다시 이용할 수 있습니다.
라이선스 키를 잃어버렸어요.
회원 가입 후 로그인하면 마이페이지에서 구매한 라이선스 키를 다시 확인할 수 있습니다.
환불이 가능한가요?
라이선스 키를 아직 활성화하지 않으셨다면 구매일로부터 7일 이내에 전액 환불이 가능합니다. 라이선스 키를 프로그램에 입력해 활성화한 경우에는 디지털 콘텐츠의 특성상 환불이 어렵습니다(전자상거래 등에서의 소비자보호에 관한 법률 제17조 제2항 준용).
백테스트 프로그램은 수익을 보장하나요?
아니요. 매매 아이디어를 과거 데이터로 검증하는 도구이며, 수익이나 승률을 보장하거나 투자를 권유하지 않습니다. 과거 결과는 미래 성과를 보장하지 않습니다.
