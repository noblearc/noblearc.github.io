채널 운영의 처음부터 끝까지, 사람이 개입하지 않아도 됩니다.

STEP 1 · 소재 발굴
채널 콘셉트를 스스로 분석하고 떡상검색기를 통해 채널에 맞는 소재를 자동으로 발굴합니다.
STEP 2 · 대본 · 이미지 · 더빙 · 편집
대본 생성부터 이미지, 음성 더빙, BGM, 편집까지 전 과정을 에이전트가 자동 처리합니다.
STEP 3 · 업로드 완전 자동화
제목 · 설명 · 태그 · 썸네일 자동 생성 및 업로드. AI 콘텐츠 사용 체크까지 자동으로 처리합니다.
STEP 4 · 채널 관리 · 성과 보고
채널 댓글 관리 자동화, 조회수 등 운영 성과를 이메일 보고서로 자동 발송합니다.
HOW IT WORKS

영상이 완성되는
6단계 자동화 흐름

딸깍모드(전자동)와 단계별 생성 모드 중 원하는 방식으로 진행하세요.

1

소재 발굴 — 리서치센터

떡상 영상 검색, 경쟁 채널 분석, 뉴스 트렌드 검색으로 지금 뜨는 소재를 발굴합니다. 무엇을 만들지 고민할 필요가 없습니다.

떡상 검색채널 분석트렌드
2

AI 대본 자동 생성

키워드 입력 또는 떡상 영상 벤치마킹으로 최상위 품질 대본이 자동 생성됩니다. 역사, 심리, 경제, 시사 등 다양한 카테고리 지원.

4가지 생성 방식다양한 카테고리
3

AI 이미지 자동 생성

대본 내용에 맞는 이미지를 자동으로 생성합니다. 쇼츠·롱폼 모두 16가지 스타일 중 선택 가능. 고정 캐릭터 설정도 지원합니다.

16가지 스타일고정 캐릭터
4

AI 음성 합성 + 자막 자동 싱크

한국어, 일본어, 영어, 독일어, 스페인어 등 7개 언어로 고품질 음성이 자동 생성됩니다. 자막은 음성과 완벽하게 싱크가 맞춰집니다.

7개 언어자막 자동 싱크
5

편집 + 렌더링

BGM, 화면 전환 효과, 씬 편집까지 자동 처리됩니다. 씬 편집기로 대본과 이미지를 직접 수정하거나 동영상 삽입도 가능합니다. 렌더링 완료 후에는 완성된 영상의 대본을 바탕으로 각 SNS에 최적화된 글을 자동으로 생성할 수 있습니다.

제목 · 설명 · 태그 · 썸네일을 AI가 자동 생성합니다. 유튜브 즉시 업로드 후 SNS 콘텐츠 자동 생성으로 이어집니다. 쿠팡파트너스 쇼츠는 영상 설명란과 댓글에 구매 링크가 자동으로 포함됩니다.

"이걸 전부 자동화할 수 없을까?" 그 질문 하나로 수년간 유튜브 채널을 운영하며 쌓아온 노하우를 프로그램 로직에 담기 시작했습니다. 단순히 빠르게 만드는 게 아니라, 실제로 조회수가 나오는 영상을 자동으로 만들어내는 구조가 필요했습니다.

그리고 한 가지 더 신경 쓴 것이 있습니다. 바로 비용입니다. 타사 프로그램들은 영상 한 편 만들 때마다 AI 비용이 따로 붙습니다. 구글 클라우드 $300 무료 크레딧을 활용해 대본·이미지·음성을 사실상 무료로 생성할 수 있도록 설계했습니다.

유튜브에 도전하는 분들의 시간도, 돈도 아껴드리고 싶었습니다. 노블아크는 그 마음으로 계속 발전하고 있습니다.

FAQ

자주 묻는 질문

Q.영상 편집 경험이 전혀 없어도 사용할 수 있나요?
네, 완전히 가능합니다. 키워드를 입력하고 버튼 하나만 누르면 대본부터 편집·업로드까지 자동으로 처리됩니다. 영상 편집 경험이 전혀 없어도 됩니다.
Q.영상 제작 비용이 따로 발생하나요?
구글 클라우드의 $300 무료 크레딧(약 44만원)을 활용하면 대본·이미지·TTS 생성이 무료입니다. 크레딧 소진 후 새 계정으로 추가 크레딧 발급도 가능합니다. 프로그램 이용료 외 영상 제작 비용은 최소화되도록 설계되어 있습니다.
Q.일본어나 영어를 몰라도 해외 채널 운영이 가능한가요?
네, 완벽하게 가능합니다. AI가 해당 언어에 최적화된 대본, 음성 더빙, 자막, 제목·설명·태그까지 전부 자동으로 처리합니다. 해당 언어를 한 글자도 몰라도 됩니다.
Q.쿠팡파트너스 쇼츠는 별도 설정이 필요한가요?
쿠팡 파트너스 계정과 API 연동만 한 번 설정해두면, 이후부터는 상품 키워드를 입력하는 것만으로 영상 제작부터 링크 삽입까지 전자동으로 진행됩니다. 별도로 링크를 복사하거나 설명란에 붙여넣을 필요가 없습니다.
Q.구매 후 어떻게 프로그램을 받을 수 있나요?
결제 완료 후 이메일로 라이선스 키, 프로그램 다운로드 링크, 사용설명서 링크가 발송됩니다. 라이선스 키는 한 번만 입력하면 이후 자동으로 활성화됩니다. Windows 전용 프로그램입니다.
Q.이용 기간이 끝나면 어떻게 되나요?
이용 기간이 만료되면 프로그램 사용이 중단됩니다. 홈페이지에서 재결제하시면 즉시 다시 이용 가능합니다.

AI 대본 자동 생성

03
AI 음성 합성 (TTS)
한국어, 일본어, 영어, 독일어, 스페인어 등 다양한 언어 지원 — 다국어 유튜브 채널 운영 가능. 다양한 목소리 · 고품질 TTS로 자동 음성 생성.

자동 자막 및 다양한 효과
BGM(배경음악), 화면 움직임 효과, 씬 전환 효과 등 다양한 효과 지원. 자막 자동 생성 및 정확한 싱크 맞춤.
05
씬 편집기
대본 · 이미지 간단하게 편집 가능. 이미지 대신 동영상 삽입도 가능. 100씬 이상 작업을 원활하게 지원합니다.

메타데이터 자동 생성
YouTube 제목 · 설명 · 태그를 AI가 자동으로 최적화합니다. 업로드 전 SEO 설정까지 원스톱 처리. 썸네일 이미지 생성도 지원합니다.
07
원클릭 렌더링 & YouTube 자동 업로드
설정 완료 후 버튼 한 번으로 완성된 MP4 파일이 출력됩니다. 롱폼(16:9)과 쇼츠(9:16) 각 프로그램별 지원. 렌더링 즉시 YouTube에 자동 업로드되는 기능도 지원합니다. 쇼츠는 대량 제작 큐(Queue) 기능으로 여러 영상을 연속 생성할 수 있습니다(대량 제작 한 번에 가능).
08
리서치 센터 — 경쟁자 분석 · 떡상 검색 · 뉴스 트렌드
채널명만 입력하면 경쟁 채널의 대시보드 · 업로드 패턴 · 최적 업로드 시간 · 수익 예측을 한눈에 분석합니다.

뉴스 트렌드 검색으로 최근 뜨고 있는 검색어 · 이슈 뉴스 검색을 통해 다양한 소재 발굴을 지원합니다.
FAQ

자주 묻는 질문

어떤 AI 모델을 사용하나요?
Google Gemini, ElevenLabs / MiniMax / OpenAI TTS를 지원합니다.
API 비용은 어떻게 되나요?
NOBLE ARC 프로그램 요금과 별도로 AI API 실사용 비용이 발생합니다. 최대한 최소화된 비용으로 영상이 제작될 수 있도록 지원합니다. Gemini는 무료 티어로 시작할 수 있어 초기 비용이 거의 없습니다.
이용 기간이 끝나면 어떻게 되나요?
이용 기간이 만료되면 프로그램 사용이 중단됩니다.

단건 결제의 경우 이용 기간 종료 후 직접 재결제하면 즉시 다시 이용 가능합니다.
Windows 외 Mac, Linux도 지원하나요?
현재는 Windows 전용으로 제공됩니다. Mac / Linux 버전은 추후 지원 예정입니다.
처음 시작할 때 어떤 준비가 필요한가요?
Google Gemini API 키만 있으면 바로 시작할 수 있습니다. Gemini는 무료 티어를 제공하므로 초기 비용 부담이 없습니다. 이후 고품질 TTS를 원하는 경우 ElevenLabs, MiniMax, OpenAI 등 추가 API 키를 선택적으로 등록할 수 있습니다.
라이선스 키를 잃어버렸어요.
회원 가입 후 로그인하면 마이페이지에서 구매한 라이선스 키를 언제든 다시 확인할 수 있습니다.
환불은 어떻게 하면 되나요?
환불을 원하시면 이메일(doedoo291@gmail.com) 또는 전화(010-3387-0352)로 문의해 주세요.

라이선스 키를 아직 활성화하지 않으셨다면 구매일로부터 7일 이내에 전액 환불이 가능합니다. 단, 라이선스 키를 프로그램에 입력하여 활성화한 경우에는 디지털 콘텐츠의 특성상 환불이 어렵습니다(전자상거래 등에서의 소비자보호에 관한 법률 제17조 제2항 준용).
프로그램에 오류가 있어서 사용을 못 했어요. 환불되나요?
프로그램 자체의 결함이나 오류로 인해 정상적인 사용이 불가능했다고 판단되는 경우에는 개별 협의를 통해 환불 또는 이용 기간 연장 조치를 취해 드립니다. 이메일(doedoo291@gmail.com) 또는 전화(010-3387-0352)로 문의해 주시면 최대한 빠르게 확인 후 안내해 드리겠습니다.
정기구독과 단건 결제의 차이는 무엇인가요?
단건 결제는 매월 직접 재결제하는 방식입니다. 이용 기간이 만료되면 사용이 중단되고, 원하실 때 직접 결제하면 됩니다. 자동 청구 걱정이 없습니다.
