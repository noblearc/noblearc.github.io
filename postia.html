Q · 01
컴퓨터를 켜두지 않아도 자동 발행되나요?
컴퓨터가 실행되어 있어야 자동 발행됩니다. PC 기반으로 동작하기 때문에 켜져 있어야 하며, 텔레그램으로 어디서든 상태 확인 및 명령이 가능합니다.
Q · 02
네이버 계정이 여러 개면 모두 등록할 수 있나요?
네이버는 여러 개 등록 가능하지만, 너무 많으면 로그인 제한이 걸릴 수 있어 적정 수로 운영하시는 것을 권장드립니다. 반면 구글블로그 · 워드프레스 · 티스토리는 등록 개수 제한이 없으니 마음껏 추가해서 운영하셔도 좋습니다.
Q · 03
API 키는 어떻게 발급받나요?
Vertex AI의 300달러 무료 크레딧(Google 신규 가입 조건 적용)을 이용하시거나 OpenAI API 키를 발급받으시면 됩니다. API 사용료는 이용료와 별도이며, 구매 후 상세 발급 가이드를 안내해 드립니다.
Q · 04
구독 기간이 끝나면 데이터는 어떻게 되나요?
데이터는 사라지지 않고 그대로 보존됩니다. 홈페이지에서 재결제하시면 기존 블로그카드와 발행 이력이 그대로 살아납니다.
Q · 05
Mac에서도 사용 가능한가요?
현재는 Windows 전용 프로그램입니다. Mac은 지원하지 않습니다.
Q · 06
설치는 어렵지 않나요?
프로그램 사용설명서를 함께 제공해 드립니다. 단계별 안내를 따라 설치 및 초기 설정을 마칠 수 있습니다.
Q · 07
블로그카드는 몇 개까지 등록할 수 있나요?
등록 제한이 없습니다. 같은 플랫폼 안에서도 계정·블로그별로 자유롭게 추가하실 수 있습니다.
Q · 08
어떤 AI 모델을 사용하나요?
글 생성 메인은 GEMINI 모델과 OPENAI 모델을 선택 사용할 수 있습니다.
