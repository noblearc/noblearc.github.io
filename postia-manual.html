1. 프로그램 소개

안녕하세요. 노블아크(NOBLE ARC)의 블로그 자동화 프로그램 포스티아(Postia)에 대해 지금부터 자세히 설명드리겠습니다.

포스티아는 블로그 운영의 전 과정을 자동화하는 프로그램입니다. 키워드 하나만 입력하면 AI가 고품질 블로그 글을 작성하고, 관련 이미지를 생성하여 네이버 블로그, 티스토리, 워드프레스, 블로거(Blogger)에 자동으로 발행합니다. 네 개의 플랫폼에 동시 발행이 가능하며, 한 번 설정해두면 스케줄에 따라 완전 자동으로 운영됩니다.

단순히 글을 생성하는 것에 그치지 않고, 쿠팡 파트너스 연동을 통한 상품 리뷰 자동화, 발행된 블로그 글을 인스타그램·스레드·페이스북 형식으로 자동 변환하는 SNS 기능, 그리고 키워드 검색량 분석을 위한 리서치 센터까지 갖추고 있습니다.

수년간의 블로그 운영 노하우를 바탕으로 검색 유입과 콘텐츠 품질을 모두 고려한 구조로 설계되었습니다. 복잡한 설정 없이 처음 한 번만 세팅하면 이후로는 최소한의 개입으로 블로그를 지속적으로 운영할 수 있습니다.

2. 구매 및 설치

⚠️ 필수 설치 사항: 이 프로그램은 Google Chrome이 반드시 설치되어 있어야 합니다.
Microsoft Edge, 네이버 웨일, Firefox 등 다른 브라우저에서는 네이버·티스토리 자동 발행이 작동하지 않습니다.
아직 Chrome이 설치되어 있지 않다면 프로그램 설치 전에 먼저 Chrome을 설치해 주세요.

noblearc.github.io에 접속하셔서 요금제를 선택하신 후 구매하시면 됩니다. 결제가 완료되면 입력하신 이메일로 라이선스 키와 프로그램 다운로드 링크가 함께 발송됩니다.

다운로드 링크를 클릭하시면 GitHub 릴리즈 페이지로 이동합니다. 파일 목록 중 Postia-Setup-버전.exe 파일 하나만 다운로드하시면 됩니다. .blockmap, .yml, Source code 파일은 다운로드하지 않으셔도 됩니다.

다운로드 받으신 설치 파일을 더블클릭합니다. 컴퓨터 환경에 따라 Windows 보호 경고창이 뜰 수 있습니다. 이 경우 추가 정보를 클릭하신 후 실행 버튼을 누르시면 됩니다. 저희 프로그램은 안전한 프로그램이니 안심하고 진행하시면 됩니다.

설치 경로 선택 화면이 나타납니다. 기본 경로를 그대로 사용하시거나 원하는 경로를 지정하신 후 Next를 클릭합니다.

시작 메뉴 폴더 선택 화면입니다. 기본값(Postia)으로 두시고 Next를 클릭합니다.

설치가 진행됩니다. 완료될 때까지 잠시 기다려주세요. 설치가 끝나면 바탕화면에 포스티아 바로가기 아이콘이 생성됩니다.

3. 라이선스 인증

프로그램을 처음 실행하시면 라이선스 인증 화면이 나타납니다. 구매 후 이메일로 받으신 라이선스 키를 입력해주세요. 키 형식은 NARC-XXXX-XXXX-XXXX이며, 하이픈(-)은 자동으로 입력됩니다.

키를 입력하신 후 인증하기 버튼을 클릭합니다. 인증이 완료되면 라이선스 키는 자동으로 저장되어 다음 실행 시에는 별도로 입력하지 않아도 됩니다.

⚠️ 라이선스는 1개의 기기에서만 사용 가능합니다. PC를 교체하시거나 기기를 변경하셔야 할 경우 13-1 기기 초기화 항목을 참고하세요.

⚠️ 인터넷이 연결되어 있어야 인증이 가능합니다. 최초 인증 후에는 최대 7일간 오프라인 환경에서도 사용 가능합니다.

4. 첫 설정 (필수 준비)

라이선스 인증을 마치셨다면 프로그램을 사용하기 위한 필수 준비를 진행합니다. 가장 중요한 것은 OpenAI API 키 등록입니다. OpenAI API 키 하나로 블로그 글 생성, AI 에이전트의 판단, 이미지 생성이 모두 작동합니다.

4-1 OpenAI API 키 발급 및 등록 (필수)

OpenAI API는 사용한 만큼 요금이 부과되는 유료 서비스입니다. ChatGPT 구독과는 별개이며, OpenAI 사이트에서 직접 결제(크레딧 충전)하셔야 사용할 수 있습니다. 처음에는 사용 한도를 낮게 걸어 두고 글 한두 편을 만든 뒤, OpenAI 대시보드의 Usage 화면에서 실제 비용을 확인해 보세요.

포스티아는 용도에 따라 아래 모델을 자동으로 사용합니다. 모델은 직접 고르지 않으셔도 됩니다.

용도사용 모델
블로그 본문 생성 · 에이전트의 주요 판단gpt-6.1-sol
가벼운 작업(분류·요약) · 이미지 분석(Vision)gpt-6-luna
이미지 생성gpt-image-2.5-sunburst (한 장당 약 $0.0105)

글 본문 생성은 사용한 글자량(토큰)에 따라 부과됩니다. 요금과 모델은 OpenAI의 정책에 따라 바뀔 수 있으니, 정확한 요금은 OpenAI 사이트에서 확인해 주세요.

platform.openai.com 이 주소를 주소창에 복사 붙여넣기 하셔서 접속하여 줍니다.

여기서 구글로 계속하기 버튼을 클릭해줍니다.

다음 사항에 모두 동의합니다에 체크를 해줍니다. 그리고 아래 계정생성 끝내기를 누르시면 간단하게 가입이 완료됩니다.

입력란에 아무거나 입력하신 후 Create organization 버튼을 클릭해줍니다.

그 다음 이메일 주소를 적으신 후 continue 버튼을 클릭해주세요.

그 다음 Generate API Key 버튼을 클릭해 줍니다.

그럼 그 다음에는 결제 화면이 뜨는데요. 포스티아의 AI 기능은 OpenAI API가 있어야 동작하므로 결제를 해주셔야 합니다.

우선 5달러부터 사용하시길 권장드립니다.

결제가 완료되셨다면 위와 같은 화면이 나옵니다. 여기서 API KEYS를 클릭해줍니다.

오른쪽 상단의 Create new secret key 버튼을 클릭하세요.

이름을 아무거나 설정하신 후 Create secret key 버튼을 클릭하시면 됩니다. 이제 API키가 생성이 됩니다.

API키는 한번만 보여줍니다. 그렇기 때문에 따로 보관해놓으시는 것을 추천드립니다. COPY 버튼을 클릭해서 복사해줍니다. 타인에게 노출되지 않도록 주의하세요.

마지막으로 포스티아 프로그램으로 돌아오셔서 설정 탭 → 필수 설정 → AI 서비스 (OpenAI)의 OpenAI API 키 입력란에 붙여넣기 하신 뒤, 화면 맨 아래의 💾 저장 및 적용 버튼을 클릭하시면 됩니다. 한번 저장하면 계속 보관되어 저장된 상태가 유지됩니다.

키를 입력한 뒤 🔗 연결 테스트 버튼을 누르면 키가 정상인지 바로 확인할 수 있습니다. 정상이면 "✅ 연결 성공!"이 표시되고, 문제가 있으면 오류 내용이 표시됩니다.

💡 사용 한도 설정 (꼭 해두세요) — 의도치 않은 과금을 방지하려면 OpenAI 사이트에서 한도를 걸어 두세요. platform.openai.com/settings/limits 에 접속하여 Monthly budget(월 예산 한도)을 설정하시면, 한도에 도달했을 때 API가 자동으로 차단됩니다.

5. 설정 탭 상세 안내

설정 탭은 프로그램의 모든 기본 설정을 관리하는 곳입니다. 처음 시작할 때 한 번 설정해두시면 이후에는 거의 변경할 일이 없습니다.

5-1 설정 화면 구성 · 이미지 스타일

설정 탭은 위에서 아래로 발행 사용량 → 이미지 스타일(필수) → 필수 설정(OpenAI) → 리서치 API → IndexNow → 텔레그램 봇 → 기기 초기화 순서로 되어 있습니다. 항목 제목을 클릭하면 접거나 펼 수 있습니다. 값을 바꾼 뒤에는 화면 맨 아래의 💾 저장 및 적용을 눌러야 적용되고, 초기화 버튼은 입력 중이던 내용을 지우고 저장된 값으로 되돌립니다.

📊 발행 사용량 카드는 설정 탭 맨 위에 있습니다. 지금까지 발행한 누적 건수와 플랫폼별·탭별(에이전트, AI포스팅, 벤치마킹) 건수, 가장 최근 발행 기록이 표시되며, 새로고침 버튼으로 최신 값을 불러옵니다.

이미지 스타일은 AI가 블로그 글에 삽입할 이미지를 생성할 때 적용되는 스타일입니다. 총 17가지 스타일 중 하나를 선택하시면 되며, 각 스타일마다 샘플 이미지가 함께 표시되어 미리 확인하실 수 있습니다.

블로그의 주제와 타겟 독자에 맞는 스타일을 선택하시면 됩니다. 예를 들어 건강·라이프스타일 블로그라면 사실적인 사진, IT·테크 블로그라면 3D 애니메이션이나 영화적 스타일이 잘 어울립니다.

5-2 리서치 API 설정 (선택)

리서치 센터의 키워드 검색량 분석 기능(네이버 키워드 도구, 데이터랩, 키워드 발굴 탭)을 사용하시려면 네이버 API 키 등록이 필요합니다. 리서치 센터를 사용하지 않으실 분은 이 항목을 건너뛰셔도 됩니다.

설정 탭의 리서치 API 섹션(처음에는 접혀 있으니 제목을 눌러 펼칩니다)에 총 5개의 항목을 입력해야 합니다. 위 3개는 네이버 검색광고(SA) API 키이고, 아래 2개는 데이터랩 API 키입니다. 두 가지는 발급받는 곳이 서로 다릅니다.

설정 탭 입력칸발급받는 곳

데이터랩 Client ID · 데이터랩 SecretNAVER API HUB (네이버 클라우드 플랫폼, ncloud.com)

이 화면에 3가지 값이 모두 있습니다. (화면의 값은 가려져 있습니다.)

  • 엑세스라이선스 오른쪽의 [복사] 버튼을 눌러 복사한 뒤, 설정 탭의 검색광고 API Key에 붙여넣습니다.
  • 비밀키 오른쪽의 [복사] 버튼을 눌러 복사한 뒤, 설정 탭의 검색광고 Secret Key에 붙여넣습니다.
  • 표 위쪽의 "현재 접근 중인 광고계정 : CUSTOMER_ID = 숫자"에서 숫자가 고객 ID입니다. 숫자만 복사해 설정 탭의 검색광고 고객 ID에 붙여넣습니다.

처음 이용하는 계정에서는 이 화면 위쪽에 "네이버 검색광고 API 서비스 신청" 같은 신청 버튼이 먼저 보일 수 있습니다. 그럴 때는 약관에 동의하고 신청을 마친 뒤 위 값이 나타나는지 확인하세요.

⚠️ 비밀키는 비밀번호와 같습니다. 다른 사람에게 보여 주거나 인터넷에 올리지 마세요. 노출이 걱정되면 같은 화면의 [재발급]을 누르면 되지만, 재발급하면 이전 값은 더 이상 쓸 수 없으니 새 값을 설정 탭에 다시 입력해야 합니다.

화면 위쪽에 "비즈머니 잔액이 부족하여 광고가 일시 중지되었습니다"라는 빨간 안내가 보여도, 이것은 광고 집행에 관한 안내입니다. API 키 발급과는 관계가 없습니다.

② 데이터랩 API 발급 — NAVER API HUB (아래쪽 2개 항목)

발급 항목: 데이터랩 Client ID, 데이터랩 Secret

⚠️ 발급 방법이 바뀌었습니다. 네이버는 개발자센터(developers.naver.com)의 검색 API·데이터랩(검색어 트렌드·쇼핑 인사이트)을 NAVER API HUB(네이버 클라우드 플랫폼)로 옮기고 있습니다. 공식 공지에 따라 2026년 7월 31일부터 개발자센터에서는 신규 신청이 막혀 있어, 새로 발급받으시는 분은 아래의 NAVER API HUB에서 발급받으셔야 합니다.

이미 개발자센터에서 키를 발급받아 쓰고 계신 분은 2027년 6월 30일까지 기존 키를 그대로 입력해 사용할 수 있습니다. 포스티아는 새 키(NAVER API HUB)와 기존 키(개발자센터)를 같은 입력칸에서 자동으로 구분합니다. (공식 공지: developers.naver.com/notice/article/32530)

2-1. 네이버 클라우드 플랫폼 회원가입

크롬 주소창에 ncloud.com을 입력해 네이버 클라우드 플랫폼에 접속합니다. 오른쪽 위의 [회원 가입]을 클릭합니다. (이미 가입한 계정이 있다면 [로그인]을 누르고 2-3 단계부터 진행하세요.)

"회원 가입을 시작합니다." 화면에서 사용할 이메일 주소를 입력하고 [이메일로 가입하기]를 누릅니다. 이 이메일이 로그인 아이디가 됩니다.

회원 가입 유형을 고릅니다. 거주 국가는 한국으로 두고, 회원 유형은 개인 회원 또는 사업자 회원 중에서 선택한 뒤 [다음]을 누릅니다. 거주 국가에 따라 결제 통화가 정해지며 가입 후에는 바꿀 수 없습니다.

[필수] 서비스 이용 약관에 체크합니다. 광고성 정보 수신 동의는 선택이므로 체크하지 않아도 됩니다. [다음]을 누릅니다.

아이디(이메일)는 앞에서 입력한 값이 들어와 있습니다. 오른쪽의 [이메일 인증]을 눌러 인증 메일을 보낸 뒤, 비밀번호와 비밀번호 확인을 입력합니다. 비밀번호 칸에 "적정"이 표시되면 사용할 수 있는 비밀번호입니다.

입력한 이메일의 받은편지함을 열어 "네이버 클라우드 플랫폼 — 메일인증 안내입니다." 메일을 찾아, 안의 [메일 인증] 버튼을 클릭합니다. 메일이 보이지 않으면 스팸함도 확인하세요.

마지막 4단계는 계정 소유자 정보입니다. 이름과 휴대 전화번호는 [실명 인증] 버튼을 눌러 본인 인증을 하면 자동으로 채워집니다. 이어서 [주소 검색]으로 기본 주소를 찾고 상세 주소를 입력한 뒤 [다음]을 누릅니다.

"회원 가입이 완료되었습니다." 화면이 나옵니다. 왼쪽에는 결제 수단 등록과 무료 이용 크레딧 안내가, 오른쪽에는 [콘솔 이동] 버튼이 있습니다.

2-2. 결제 수단 등록 (필수)

결제 수단을 등록하지 않은 상태에서 콘솔에 들어가면 위와 같이 "서비스 이용이 불가능한 계정입니다."라는 안내가 나옵니다. 안내 문구대로 [과금정보 및 비용관리 > 결제 정보 관리]에서 결제수단을 등록해야 정상적으로 이용할 수 있습니다.

콘솔 오른쪽 위의 계정(내 이름) 아이콘을 눌러 메뉴를 열고 [과금 정보 및 비용 관리]를 클릭합니다.

왼쪽 메뉴의 [결제 정보 관리]로 들어가 자동이체 항목의 [결제 수단 등록] 버튼을 누르고, 화면 안내에 따라 카드를 등록합니다. 화면의 안내 문구에 따르면 개인 고객은 신용카드 자동납부만 지원되고, 한국 외 이용자는 3D Secure 신용카드만 등록할 수 있습니다.

⚠️ 결제 관련 꼭 확인하세요.

• NAVER API HUB는 현재 한시적으로 무료로 제공된다고 네이버가 공지했습니다. 다만 이후 유료 요금제가 도입될 수 있다고 함께 안내되어 있으니, Application 등록 화면의 [요금 안내] 버튼으로 요금 정책을 가끔 확인하세요.

• 이 가이드에서는 NAVER API HUB 외의 서버, 스토리지 등 다른 서비스를 신청하지 않습니다. 다른 서비스를 신청하면 사용한 만큼 요금이 청구될 수 있습니다.

• [청구서] 화면에서 청구 내역이 없는지(0건) 가끔 확인하면 안심할 수 있습니다. 비용 데이터는 매일 오전에 갱신됩니다.

2-3. NAVER API HUB 서비스 이용 신청

콘솔 왼쪽 위의 [Menu]를 클릭해 메뉴를 열고 [All Services]를 클릭합니다.

전체 서비스 목록에서 Application Services 항목 맨 위에 있는 [NAVER API HUB]를 클릭합니다.

NAVER API HUB 소개 화면이 열립니다. 이 서비스는 Data Lab(쇼핑인사이트 및 검색어 트렌드 조회)과 NAVER 검색(블로그, 이미지, 뉴스 등 검색) API를 제공합니다. 처음 이용할 때는 [+ 서비스 이용 신청] 버튼이 있습니다. 클릭합니다.

"서비스 이용 신청" 팝업에서 (필수) 이용 약관에 동의합니다와 (필수) 개인정보 제3자 제공에 동의합니다 두 곳에 모두 체크한 뒤 [확인]을 누릅니다.

2-4. Application 등록과 키 확인

신청이 끝나면 같은 화면의 버튼이 [+ Application 등록]으로 바뀝니다. 클릭합니다.

"Application 등록" 1단계 API 선택 화면에서 카드 오른쪽 위의 체크 박스로 사용할 API를 고릅니다. 포스티아에서는 아래 3가지를 체크하세요.

  • 쇼핑인사이트 (Data Lab Shopping Insight API) — 데이터랩 쇼핑인사이트 탭에 필요합니다.
  • 검색어트렌드 (Data Lab Search Trend API) — 데이터랩 통합검색 트렌드 탭과 키워드 판단에 필요합니다.
  • 블로그 (NAVER Search Blog API) — 선택 사항입니다. 체크해 두면 키워드 발굴에서 블로그 문서 수로 경쟁도를 더 정밀하게 재는 데 쓰입니다.

카드의 [요금 안내]와 [개발 가이드] 버튼으로 요금과 사용법을 확인할 수 있습니다. 선택이 끝나면 아래 [다음]을 누릅니다.

2단계 Application 정보 입력입니다. 위쪽 "선택한 Application"에 방금 체크한 3가지가 표시됩니다. Application 이름에 알아보기 쉬운 이름을 입력하고(예: postia) [완료]를 누릅니다.

왼쪽 목록에서 방금 만든 Application을 선택한 뒤 API 관리 아래의 [인증 정보] 버튼을 누르면 "인증 정보" 팝업이 열립니다. (화면의 값은 가려져 있습니다.)

  • Client ID(X-NCP-APIGW-API-KEY-ID) 오른쪽의 복사 아이콘을 눌러 복사한 뒤, 설정 탭의 데이터랩 Client ID에 붙여넣습니다.
  • Client Secret(X-NCP-APIGW-API-KEY) 오른쪽의 복사 아이콘을 눌러 복사한 뒤, 설정 탭의 데이터랩 Secret에 붙여넣습니다.

팝업 뒤쪽의 표에서 API별 사용량 한도를 확인할 수 있습니다. 예시 화면에서는 블로그 검색이 하루 25,000회·한 달 775,000회, 데이터랩이 한 달 50,000회로 표시되어 있습니다. 한도를 넘으면 해당 기능이 "호출 한도 초과" 메시지를 보여 줍니다.

⚠️ Client Secret이 다른 사람에게 노출되었다면 같은 팝업의 [재발급]을 눌러 새로 받으세요. 재발급하면 이전 Secret은 사용할 수 없습니다.

2-5. 포스티아에 입력하고 확인하기

설정 탭의 리서치 API 섹션에 5개 값을 모두 입력하고 오른쪽 아래 [저장 및 적용]을 누릅니다. 그다음 리서치 센터 → 데이터랩 탭을 열어 맨 위의 상태가 "● API 연결됨"(초록)인지 확인하고, 통합검색 트렌드와 쇼핑인사이트에서 키워드를 한 번 조회해 보세요.

💡 조회가 안 되고 "인증 실패" 안내가 나오면, (1) Application을 만들 때 검색어트렌드·쇼핑인사이트를 체크했는지, (2) Client ID와 Client Secret을 서로 바꿔 붙여넣지 않았는지, (3) 앞뒤에 공백이 섞이지 않았는지를 확인하세요. 검색광고 키(위쪽 3개)는 리서치 센터 → 네이버 키워드 도구 탭에서 조회가 되는지로 확인할 수 있습니다.

5-3 IndexNow 설정 (워드프레스 전용, 선택)

IndexNow는 워드프레스 블로그에서만 사용 가능한 기능입니다. 새 글을 발행한 직후 네이버와 빙(Bing) 검색엔진에 즉시 색인을 요청하는 기능으로, 검색 노출 속도를 높이는 데 도움이 됩니다.

워드프레스 관리자 왼쪽 메뉴에서 [플러그인] → [플러그인 추가]를 클릭합니다.

오른쪽 검색창에 IndexNow를 입력합니다. 검색 결과에서 IndexNow Plugin (작성자: bingwebmastertools)을 찾아 [지금 설치] 버튼을 클릭한 뒤 활성화합니다. 이것만으로 글 발행 시 색인 요청이 자동으로 처리됩니다.

5-4 텔레그램 봇 설정 (선택)

텔레그램 봇을 연결하면 블로그 발행 결과를 실시간으로 알림 받을 수 있고, 텔레그램에서 직접 명령을 보내 원격으로 프로그램을 제어할 수 있습니다. 자세한 사용법은 12번 텔레그램 원격 제어 항목을 참고하세요.

봇 설정 순서는 다음과 같습니다.

① 텔레그램 앱에서 @BotFather를 검색하여 대화를 시작합니다. /newbot 명령을 입력하고 봇 이름과 사용자명을 입력하시면 봇 토큰이 발급됩니다.

② 발급받은 Bot Token을 설정 탭의 Bot Token 입력란에 붙여넣고 [봇 연결] 버튼을 클릭합니다.

③ 연결한 봇과 대화를 시작하여 /myid 명령을 전송하면 숫자로 된 Chat ID가 반환됩니다. 이 Chat ID를 설정 탭에 입력합니다. 여러 명에게 알림을 보내려면 Chat ID를 쉼표로 구분하여 입력하시면 됩니다.

④ [테스트 메시지] 버튼으로 연결 상태를 확인하실 수 있습니다.

6. 플랫폼 계정 등록

포스티아는 네이버 블로그, 티스토리, 워드프레스, 블로거(Blogger) 네 개의 플랫폼에 발행할 수 있습니다.

포스티아의 탭은 계정을 관리하는 방식이 두 가지로 나뉩니다. 어느 탭을 사용하실지에 따라 계정 등록 방법이 다르므로 아래 내용을 먼저 확인하세요.

① AI 에이전트 탭: 에이전트 탭 안에서 + 블로그 추가 버튼으로 블로그를 직접 등록합니다. 블로그마다 계정 정보, 주제, 일일 발행 한도를 개별적으로 관리합니다. 자세한 내용은 7번 AI 에이전트 탭 항목을 참고하세요.

② AI 포스팅 · 벤치마킹 · 홍보 발행 · 리뷰 포스팅 · 쿠팡 파트너스 탭: 설정 탭에 입력한 계정 정보를 사용합니다. 각 탭 화면에 플랫폼별 로그인 버튼이 있으며, 버튼을 클릭하면 설정 탭의 계정으로 자동 로그인됩니다.

6-1 네이버 블로그

네이버 블로그 계정을 등록할 때는 아이디와 비밀번호를 입력합니다.

⚠️ 네이버는 반드시 2단계 인증(2차 인증)을 해제하셔야 합니다. 2단계 인증이 활성화되어 있으면 자동 로그인이 불가능합니다. 네이버 계정 보안 설정에서 해제 후 사용하세요.

⚠️ 네이버 자동 발행은 Google Chrome 전용입니다. Microsoft Edge, 네이버 웨일 등 다른 브라우저에서는 작동하지 않습니다.

카테고리 항목은 선택 사항입니다. 네이버 블로그에 설정하신 카테고리명을 정확히 입력하시면 해당 카테고리로 글이 발행됩니다. 비워두시면 기본 카테고리로 발행됩니다.

6-2 티스토리

티스토리는 카카오 계정으로 로그인합니다. 티스토리 계정이 아닌 카카오 이메일과 카카오 비밀번호를 입력하세요.

⚠️ 카카오 계정도 반드시 2단계 인증을 해제하셔야 합니다.

⚠️ 티스토리 공개 발행 시 DKAPTCHA(캡차)가 차단할 수 있습니다. 자동화 환경에서는 임시저장(비공개)으로 발행하신 후 티스토리 관리자에서 직접 공개로 전환하시는 것을 권장합니다.

⚠️ 티스토리 자동 발행은 Google Chrome 전용입니다. Microsoft Edge, 네이버 웨일 등 다른 브라우저에서는 작동하지 않습니다.

6-3 워드프레스

워드프레스는 사이트 URL, 사용자명, 앱 비밀번호(App Password)를 입력하여 등록합니다.

사이트 URL: https://myblog.com 형식으로 입력하세요. 끝에 슬래시(/) 없이 입력합니다.

사용자명: 워드프레스 관리자 아이디입니다.

App Password: 일반 로그인 비밀번호가 아닌 전용 앱 비밀번호입니다. 워드프레스 관리자 → 사용자 → 프로필 하단의 애플리케이션 비밀번호 섹션에서 생성할 수 있습니다. 생성 직후 한 번만 표시되므로 바로 복사해 입력하세요.

6-4 블로거 (Blogger)

블로거는 Google 계정 인증(OAuth)을 통해 연결합니다. Google Cloud Console에서 발급받은 Client ID와 Client Secret을 입력한 후 연결 버튼을 클릭하면 구글 로그인 팝업이 열립니다. 블로거를 운영하는 구글 계정으로 로그인하고 권한을 허용하시면 인증이 완료됩니다. 최초 1회만 브라우저 팝업으로 인증하며, 이후에는 자동으로 유지됩니다.

Client ID / Client Secret: Google Cloud Console → API 및 서비스 → 사용자 인증 정보에서 OAuth 2.0 클라이언트 ID를 생성(유형: 데스크톱 앱)하시면 발급됩니다.

7. AI 에이전트 탭 (자동 운영)

AI 에이전트 탭은 포스티아의 핵심 기능입니다. 등록된 블로그들을 스케줄에 따라 자동으로 운영해주는 탭입니다. 직접 키워드를 입력하지 않아도 AI가 등록된 블로그 주제를 기반으로 인기 키워드를 발굴하고 글을 생성하여 발행합니다.

⚠️ AI 에이전트 탭은 자체 블로그 카드 목록을 사용합니다. AI 포스팅·벤치마킹·홍보 발행 등 다른 탭과 블로그 목록을 공유하지 않습니다. 에이전트로 자동 운영할 블로그는 이 탭에서 별도로 등록해야 합니다.

화면 상단의 실행 제어 영역에서 에이전트를 즉시 실행하거나 중단할 수 있습니다. 지금 즉시 실행 버튼을 누르면 스케줄 시간과 관계없이 바로 발행이 시작됩니다.

스케줄 설정 영역에서는 에이전트가 자동으로 작동할 시간과 요일을 설정합니다. 실행 시각과 요일을 지정한 뒤 스케줄 적용 버튼을 클릭해야 설정이 저장됩니다. 실행 시각 추가 버튼으로 하루에 여러 번 실행 시간을 등록할 수 있습니다.

💡 WordPress 백링크 허브 옵션을 활성화하면 WordPress에 발행된 글 URL을 다른 플랫폼 본문 하단에 백링크로 자동 삽입합니다.

스케줄 설정 아래에는 등록된 블로그 목록이 표시됩니다. 각 블로그 카드에서 플랫폼 종류, 소스 방식(자동/키워드), 오늘 발행 건수, 마지막 발행 시각을 한눈에 확인할 수 있습니다. 활성화 토글로 블로그별 자동 발행을 개별적으로 켜고 끌 수 있으며, 편집·삭제 버튼으로 설정을 수정하거나 블로그를 제거할 수 있습니다.

아래의 발행 통계 표에서는 블로그별 총 발행 건수, 오늘 발행 건수, 연속 실패 횟수, 마지막 발행 일시를 한 번에 볼 수 있습니다. 연속 실패 횟수가 높아진 블로그가 있다면 계정 정보나 플랫폼 설정을 점검해 보세요.

블로그 추가 방법 (플랫폼별)

오른쪽 상단의 + 블로그 추가 버튼을 클릭하면 블로그 등록 화면이 열립니다. 플랫폼을 선택하면 해당 플랫폼에 맞는 입력 항목이 표시됩니다.

네이버

플랫폼에서 Naver를 선택하면 위와 같은 입력 화면이 표시됩니다.

블로그 이름: 목록에서 구분하기 위한 이름입니다. 실제 블로그 이름과 달라도 됩니다.

블로그 주제 / 방향 (필수): AI가 키워드를 발굴할 때 기준이 되는 주제입니다. "경제, 재테크, 금융 투자"처럼 구체적으로 입력할수록 글의 방향이 정확해집니다.

일일 발행 한도: 하루에 자동 발행할 최대 건수입니다. 처음에는 1~2건으로 시작하세요.

이미지 스타일: 기본값은 자동(콘텐츠 분석 후 선택)이며 블로그마다 다르게 지정할 수 있습니다.

네이버 아이디 / 비밀번호: 자동 로그인에 사용됩니다. 반드시 2단계 인증을 해제하신 후 입력하세요.

네이버 카테고리 (선택): 카테고리명을 입력하고 저장 버튼으로 보관하면 다음에 드롭다운으로 빠르게 선택할 수 있습니다. 비워두면 기본 카테고리로 발행됩니다.

티스토리

플랫폼에서 Tistory를 선택하면 카카오 계정 입력 항목이 표시됩니다. 티스토리 계정이 아닌 카카오 이메일과 카카오 비밀번호를 입력하세요. 카카오 계정도 2단계 인증을 반드시 해제해야 합니다.

⚠️ 티스토리 공개 발행 시 DKAPTCHA(캡차)가 차단할 수 있습니다. 자동화 환경에서는 임시저장(비공개)으로 설정 후 티스토리 관리자에서 직접 공개로 전환하는 것을 권장합니다.

워드프레스

플랫폼에서 WordPress를 선택하면 사이트 URL, 사용자명, App Password 입력 항목이 표시됩니다. App Password는 일반 로그인 비밀번호가 아닌 전용 앱 비밀번호입니다. 워드프레스 관리자 → 사용자 → 프로필 하단 애플리케이션 비밀번호 섹션에서 생성 후 바로 복사해 입력하세요. 포스트 언어는 기본값 한국어이며 해외 블로그 운영 시 변경 가능합니다.

블로거 (Blogger)

플랫폼에서 Blogger를 선택하면 Google OAuth 인증 항목이 표시됩니다. Google Cloud Console에서 발급받은 Client ID와 Client Secret을 입력한 뒤 연결 버튼을 클릭합니다. 구글 로그인 팝업에서 블로거를 운영하는 구글 계정으로 로그인하고 권한을 허용하면 인증이 완료됩니다. 최초 1회만 팝업 인증이 필요하며 이후에는 자동 유지됩니다.

에이전트 작동 방식

에이전트를 시작하면 프로그램이 등록된 블로그들을 순서대로 확인합니다. 해당 블로그의 오늘 발행 건수가 일일 한도에 도달하지 않은 경우, 블로그 주제를 기반으로 인기 키워드를 자동으로 발굴하고 글을 생성하여 발행합니다.

발행이 완료되면 발행된 글의 제목과 URL이 로그에 표시됩니다. 텔레그램 봇이 설정되어 있다면 발행 완료 알림도 함께 수신됩니다.

💡 처음 운영하실 때는 일일 한도를 1~2건으로 설정하시고 생성되는 글의 품질과 발행 상태를 먼저 확인하시는 것을 권장합니다. 이상이 없으면 점차 늘려가시면 됩니다.

8. 포스팅 센터

포스팅 센터는 원하는 키워드나 내용으로 직접 글을 생성하고 발행하는 탭입니다. AI 에이전트가 자동 운영이라면, 포스팅 센터는 수동 제어 방식입니다. AI 포스팅, 벤치마킹 포스팅, 홍보 발행, 리뷰 포스팅, 발행이력 서브 탭으로 구성되어 있습니다.

8-1 AI 포스팅

AI 포스팅은 키워드를 입력하면 AI가 해당 키워드로 블로그 글을 생성하여 선택한 블로그에 즉시 발행하는 기능입니다.

① KEYWORD 입력란에 원하는 키워드를 입력합니다. 단순 키워드만 입력하면 됩니다. (예: 다이어트 식단추천)

② 분위기를 선택하고 주제/카테고리를 클릭하여 글의 성격을 지정합니다.

③ 워드프레스 블로그가 등록되어 있다면 WordPress 백링크 허브 옵션을 반드시 체크하세요. 다른 플랫폼 발행 글 하단에 워드프레스 URL이 백링크로 삽입되어 SEO에 도움이 됩니다.

④ 발행할 블로그를 체크박스로 선택합니다. 여러 블로그를 동시에 선택할 수 있습니다.

⑤ 발행 옵션을 선택합니다. 임시저장은 각 플랫폼 임시저장함에 저장되고, 즉시발행은 바로 공개 발행됩니다.

⑥ 고급 옵션(선택, 접혀 있으니 제목을 눌러 펼칩니다): 네이버 상위 블로그 크롤링 참고를 켜면 네이버 상위 글을 참고해 글을 쓰고(크롤링 수 지정), 볼드 강조 키워드(쉼표 구분)는 본문에서 자동으로 굵게 표시되며, 삽입 링크에는 링크 주소와 표시 문구를 넣을 수 있습니다. 이미지 폴더 경로를 지정하면 AI 이미지 대신 내 사진을 쓰고, 비워 두면 AI가 이미지를 자동 생성합니다.

⑦ [포스팅 생성 시작] 버튼을 클릭합니다. AI가 글 생성·이미지 생성·발행까지 자동으로 진행하며 통상 2~10분 소요됩니다.

⚠️ 발행 중에는 버튼이 비활성화됩니다. 발행이 완료될 때까지 프로그램을 종료하지 마세요.

8-2 벤치마킹 포스팅

유튜브 대본, 다른 블로그 글, 뉴스 기사 등 참고할 텍스트를 입력하면 AI가 그 내용을 바탕으로 저작권에 안전한 새 블로그 글을 생성·발행하는 기능입니다.

① 참고 텍스트 입력란에 벤치마킹할 내용을 붙여넣습니다. 유튜브 자막, 뉴스 기사 본문, 블로그 포스트 등 모두 가능합니다.

② 타겟 키워드는 가능하면 반드시 설정하세요. 검색 유입에 직접적인 영향을 줍니다.

③ 워드프레스 블로그가 있다면 WordPress 백링크를 체크하세요.

④ 발행할 블로그를 선택한 후 [생성 및 발행] 버튼을 클릭합니다.

8-3 홍보 발행

홍보할 URL을 입력하면 AI가 해당 페이지를 분석하여 자연스러운 홍보 블로그 글을 생성·발행하는 기능입니다. 키워드마다 독립적인 글이 생성됩니다.

① SOURCE URL에 홍보 대상 URL을 필수로 입력합니다. (예: 크몽 긱 페이지, 스마트스토어 상품 페이지 등)

② KEYWORDS에 홍보 키워드를 입력합니다. 줄바꿈으로 여러 개 입력하면 각 키워드별로 모든 등록 블로그에 발행됩니다.

③ 발행 간격을 설정합니다. 키워드가 여러 개일 경우 각 발행 사이의 간격(분)을 지정합니다.

④ 고급 글쓰기 스타일(선택): 공감 도입부·오감 스토리텔링·8:2 솔직함의 법칙이 적용된 더 자연스러운 홍보 글을 원하시면 체크하세요.

⑤ 이미지 배치: 홍보 페이지 관련 이미지가 저장된 폴더를 지정하면 해당 이미지가 글에 삽입됩니다.

⑥ [홍보 포스팅 시작] 버튼을 클릭하면 발행이 시작됩니다.

8-4 리뷰 포스팅

음식점·카페·상품 등을 직접 방문하거나 체험한 사진을 기반으로 AI가 리뷰 블로그 글을 생성·발행하는 기능입니다.

① 리뷰 유형을 선택합니다. (음식점, 카페, 상품 등 유형에 맞게 선택)

② 사진 폴더 선택: 리뷰에 사용할 사진이 저장된 폴더를 지정합니다. 선택한 폴더의 이미지가 미리보기로 표시됩니다.

③ 참고 링크/텍스트: 참고할 다른 리뷰 글의 링크나 텍스트를 입력하면 더 풍부한 내용의 글이 생성됩니다. (선택 사항)

④ 장소 주소를 입력하면 글 마지막 부분에 지도가 자동으로 삽입됩니다. (선택 사항)

⑤ 협찬 고지: 협찬·제공을 받은 경우 반드시 체크하고 제공받은 내용을 입력하세요. 체크 시 글 마지막에 협찬 고지 문구가 자동 삽입됩니다.

⑥ 고급 글쓰기 스타일(선택): 보다 자연스럽고 감성적인 리뷰 글을 원하시면 체크하세요.

⑦ 발행할 블로그를 선택한 후 [생성 및 발행] 버튼을 클릭합니다.

8-5 발행이력

발행이력 탭에서는 지금까지 발행된 모든 글의 기록을 확인할 수 있습니다. 발행 일시, 제목, 플랫폼, 성공 여부가 목록으로 표시됩니다.

상단의 필터 버튼으로 전체, 성공, 실패 항목을 구분하여 볼 수 있습니다. 발행에 실패한 항목은 재시도 버튼으로 다시 발행을 시도할 수 있습니다. 발행된 글의 제목을 클릭하면 해당 블로그 포스트를 바로 확인할 수 있습니다.

9. 쿠팡 파트너스

쿠팡 파트너스 탭은 쿠팡 상품을 검색하여 AI 리뷰 글을 자동으로 생성하고 블로그에 발행하는 기능입니다. 쿠팡 제휴 링크가 글에 자동으로 삽입되어 구매 발생 시 수익이 발생합니다.

API 키 설정

쿠팡 파트너스 기능을 사용하려면 쿠팡 파트너스 API 키가 필요합니다. partners.coupang.com에 접속하여 가입 후 계정관리 → API 키 관리에서 Access Key와 Secret Key를 발급받으실 수 있습니다. 발급받은 키를 쿠팡 파트너스 탭의 API 설정 항목에 입력 후 [키 저장] 버튼을 클릭하세요.

사용 방법

① 검색어 입력란에 리뷰할 상품명을 입력하고 결과 개수를 선택한 뒤 [상품 검색] 버튼을 클릭합니다.

② 검색 결과 목록에서 원하는 상품을 클릭하여 선택합니다. 상품명·가격·카테고리가 표시되며 [링크 복사] 버튼으로 쿠팡 파트너스 링크를 바로 복사할 수도 있습니다.

③ 발행할 블로그를 선택합니다. 등록된 블로그 목록에서 체크박스로 발행할 블로그를 고릅니다. 네이버·블로거·워드프레스·티스토리 모두 지원합니다.

⚠️ 네이버 블로그에는 쿠팡 포스팅을 자주 발행하지 않도록 주의하세요.

④ 글쓰기 스타일 옵션(선택): 고급 글쓰기 스타일을 켜면 공감 도입부·오감 스토리텔링·8:2 솔직함의 법칙을 적용한 리뷰 글이 생성됩니다.

⑤ [선택 상품으로 리뷰 포스트 생성 발행] 버튼을 클릭하면 AI가 리뷰 글을 자동 생성하여 선택한 블로그에 발행합니다. 쿠팡 파트너스 제휴 링크가 글에 자동 삽입됩니다.

10. SNS 변환

SNS 변환 기능은 작성된 블로그 글을 인스타그램, 스레드(Threads), 페이스북에 맞는 형식으로 자동 변환해주는 기능입니다. 포스팅 센터 탭 내에 있습니다.

각 SNS 플랫폼은 최적의 글자 수와 문체가 다릅니다. 포스티아는 플랫폼 특성에 맞게 자동으로 변환합니다.

플랫폼특징
인스타그램 피드150자 내외, 가치 전달 + 프로필 링크 유도 구조
인스타그램 스토리2줄 이내의 짧고 강렬한 문구
스레드 (Threads)100~200자, 구어체의 자연스러운 인사이트
페이스북500~1,000자, 정보성 본문과 참여 유도 문구

사용 방법은 다음과 같습니다.

  • 글 불러오기: 버튼을 클릭하여 발행된 블로그 글을 불러옵니다.
  • SNS 선택: 오른쪽 패널에서 변환할 SNS 플랫폼(Instagram 피드·스토리, Threads, Facebook)을 선택합니다. SNS별로 이미지 사이즈도 함께 선택·저장할 수 있습니다.
  • 생성 버튼 클릭: 발행할 SNS를 선택한 후 [생성] 버튼을 클릭합니다. AI가 각 플랫폼 형식에 맞게 글을 자동 변환합니다.
  • 생성된 텍스트를 복사하여 각 SNS에 직접 게시하시면 됩니다.

11. 리서치 센터

리서치 센터는 블로그 운영에 필요한 키워드 분석, 트렌드 파악, 공공데이터 수집을 한 곳에서 처리할 수 있는 탭입니다. 뉴스 트렌드 · 네이버 키워드 도구 · 데이터랩 · 키워드 발굴 · 구글 롱테일 키워드 · 공공데이터 총 6개의 서브 탭으로 구성되어 있습니다.

⚠️ 네이버 키워드 도구 · 데이터랩 · 키워드 발굴 탭은 네이버 검색광고 API 또는 데이터랩 API 키가 등록되어 있어야 사용 가능합니다. 5-2 리서치 API 설정 항목을 먼저 완료하세요. (데이터랩 키는 NAVER API HUB에서 발급받습니다.)

뉴스 트렌드

오늘 실시간으로 떠오르는 이슈와 뉴스를 한눈에 확인하는 탭입니다.

검색어 입력 + 뉴스 수집 버튼: 원하는 키워드를 입력하고 뉴스 수집 버튼을 클릭하면 해당 키워드 관련 최신 뉴스가 카드 형태로 표시됩니다.

오늘의 화제 버튼: 버튼 클릭 시 오늘 실시간으로 주목받는 이슈들을 자동으로 수집해 표시합니다.

실시간 트렌드 태그: 화면 하단에 현재 실시간 순위 키워드들이 태그 버튼으로 나열됩니다. 태그를 클릭하면 해당 이슈의 뉴스 목록이 펼쳐집니다.

뉴스 카드 클릭: 뉴스 카드를 클릭하면 해당 뉴스의 본문 내용을 프로그램 내 팝업으로 바로 확인할 수 있습니다.

💡 시의성 있는 트렌드 주제로 블로그 글을 쓰고 싶을 때 활용하세요. 실시간 이슈 키워드를 발굴하여 포스팅 센터에서 즉시 글 생성에 활용할 수 있습니다.

네이버 키워드 도구

네이버 검색광고 API를 통해 키워드의 월간 검색량과 연관 키워드를 조회하는 탭입니다. 화면 상단의 API 연결 상태가 녹색으로 표시되어 있어야 사용 가능합니다.

키워드 입력란: 조회할 키워드를 쉼표(,)로 구분하여 최대 5개까지 입력합니다. 예: 다이어트,운동 / 강남맛집,홍대카페

연관 키워드 조회 버튼: 버튼 클릭 시 입력한 키워드와 연관된 키워드 목록과 함께 PC 월간 검색량, 모바일 월간 검색량, 합계, 경쟁도, 블로그 발행 수를 표로 보여줍니다.

CSV 내보내기 버튼: 조회된 결과 전체를 CSV 파일로 저장합니다. 엑셀에서 열어 추가 분석에 활용할 수 있습니다.

💡 검색량이 높고 경쟁도가 낮은 키워드일수록 블로그 상위 노출에 유리합니다. 월 1,000~10,000 수준의 검색량에 경쟁도 낮음·중간 키워드를 우선적으로 활용하세요.

데이터랩 — 통합검색 트렌드

네이버 데이터랩 API를 통해 키워드의 검색량 트렌드를 기간별로 비교하는 탭입니다. 통합검색 트렌드와 쇼핑인사이트 두 개의 서브 탭으로 구성됩니다.

통합검색 트렌드는 네이버 통합검색에서 키워드가 얼마나 많이 검색됐는지 기간별 트렌드를 비교합니다. 수치(0~100)는 조회 기간 내 최고 검색량을 100으로 환산한 상대값입니다.

그룹 입력 (최대 3개): 각 그룹에 비교할 키워드를 입력합니다. 같은 의미의 동의어(예: 다이어트, 살빼기, diet)는 한 그룹에 쉼표로 묶으면 하나의 그룹으로 합산됩니다.

기간 / 단위: 조회할 날짜 범위와 집계 단위(일별/주별/월별)를 선택합니다.

트렌드 조회 버튼: 클릭 시 기간별 트렌드 데이터가 표로 표시됩니다. 수치가 90 이상이면 진빨강(최정점), 70~89는 빨강(급상승), 40~69는 주황(관심 상승), 20~39는 회색(평균 이상)으로 색상 구분됩니다.

데이터랩 — 쇼핑인사이트

네이버 쇼핑에서 카테고리별 검색 트렌드를 비교하는 탭입니다. 어떤 카테고리가 이 시기에 더 많이 검색됐는지 파악하여 블로그 주제 선정에 활용할 수 있습니다.

조회 방식: 카테고리 트렌드 비교 모드를 선택합니다.

카테고리 선택 (최대 3개): 비교할 쇼핑 카테고리를 드롭다운에서 선택합니다. 예: 패션의류 vs 화장품/미용 vs 식품.

기간 / 단위: 통합검색 트렌드와 동일하게 날짜 범위와 집계 단위를 설정합니다.

조회 버튼: 선택한 카테고리들의 기간별 트렌드 데이터를 표로 비교합니다. 수치(0~100)는 기간 내 최고점 대비 상대 비율입니다.

키워드 발굴

블로그 주제를 입력하면 AI가 다각도로 키워드를 탐색하고, 경쟁 강도를 정밀 분석해 4단계 등급으로 자동 분류해주는 탭입니다. 네이버 검색광고 API와 OpenAI API 키 설정이 필요합니다.

주제 입력란: 블로그 주제를 입력합니다. 예: 30대 직장인 건강관리, 다이어트 식단, 강아지 훈련법

키워드 발굴 시작 버튼: 클릭 시 AI가 주제 관련 키워드를 자동으로 탐색하고 경쟁도 분석을 시작합니다. 수백 개의 키워드를 분석하므로 완료까지 수 분이 소요될 수 있습니다.

중지 버튼: 발굴 중간에 작업을 중단합니다. 중단 시점까지 수집된 결과는 그대로 표시됩니다.

CSV 내보내기 버튼: 발굴된 키워드 결과 전체를 CSV 파일로 저장합니다.

에이전트 풀에 저장 버튼: 결과 중 황금 등급 키워드만 추려서 에이전트 키워드 풀에 저장합니다. 저장된 키워드는 AI 에이전트 자동 운영 시 발행 키워드로 우선 사용됩니다.

입력 주제 중심 증폭 옵션: 체크하면 입력 키워드를 앞에 붙인 복합어 위주로 탐색합니다(예: 다이어트 → 다이어트식단, 다이어트운동…). 주제에서 벗어난 키워드가 나오는 것을 방지하고 싶을 때 사용하세요.

등급 기준

🥇 황금: 롱테일 저경쟁 키워드. 신생·일반 블로그도 상위 노출 가능

🔴 최상급: 높은 검색 수요 + 낮은 경쟁. 도전 가치 높음

🟠 상급: 도전 가능한 수준의 경쟁도

🔵 중급: 경쟁이 있는 키워드

결과 표에는 등급, 키워드, PC 월간 검색량, 모바일 월간 검색량, 합계, 경쟁도, 블로그 수, 제목 일치 건수, 황금 지수가 표시됩니다. 황금 지수는 검색량 대비 블로그 수를 기반으로 산출한 점수로, 높을수록 유리한 키워드입니다.

구글 롱테일 키워드

구글 자동완성 데이터를 기반으로 API 키 없이 롱테일 키워드를 발굴하는 탭입니다. 실제 사람들이 검색하는 자동완성어를 수집하므로 네이버 키워드 도구의 시드 키워드로 활용하기 좋습니다.

키워드 입력란: 발굴할 기준 키워드를 입력합니다.

발굴 시작 버튼: 클릭 시 구글 자동완성 데이터를 수집하기 시작합니다. 수집 중에도 결과가 실시간으로 추가됩니다.

중지 버튼: 수집을 중단합니다.

확장 모드 옵션: 체크하면 접미어 30개 + 연령·성별 조합으로 훨씬 더 많은 키워드(약 300~500개)를 수집합니다.

YouTube 자동완성 포함 옵션: 체크하면 구글 자동완성뿐 아니라 YouTube 검색 자동완성어도 함께 수집합니다. 영상 기반 트렌드 키워드까지 파악할 수 있습니다.

결과 목록 체크박스: 원하는 키워드를 최대 5개까지 체크박스로 선택할 수 있습니다. 소스(google/YouTube) 컬럼에서 어디서 수집된 키워드인지 확인됩니다.

네이버 발굴 전송 버튼 (최대 5개): 선택한 키워드를 키워드 발굴 탭으로 즉시 전송합니다. 전송 즉시 키워드 발굴 탭이 열리며 경쟁도 분석이 자동 시작됩니다.

공공데이터 — 복지·지원금

국가복지정보시스템에서 복지서비스 및 지원금 정보를 검색하는 탭입니다. 복지·지원금 관련 블로그 콘텐츠를 작성할 때 공식 정보를 빠르게 수집하는 데 활용할 수 있습니다.

검색창: 찾고 싶은 복지서비스 키워드를 입력합니다. 예: 청년지원, 육아수당, 장애인복지

검색 버튼: 클릭 시 국가복지정보시스템에서 관련 서비스 목록을 가져옵니다.

자세히 버튼: 각 복지서비스 카드의 자세히 버튼을 클릭하면 해당 서비스의 상세 내용을 확인할 수 있습니다.

복사 버튼: 카드의 복사 버튼을 클릭하면 서비스명, 기관명, 설명, 상세 URL이 클립보드에 복사됩니다. 글 작성 시 바로 붙여넣기하여 활용할 수 있습니다.

12. 텔레그램 원격 제어

텔레그램 봇이 설정되어 있다면 PC를 직접 조작하지 않고도 스마트폰 텔레그램 앱에서 포스티아를 원격으로 제어하고 발행 결과를 실시간으로 받아볼 수 있습니다.

⚠️ 텔레그램 원격 제어는 에이전트 탭, AI 포스팅, 벤치마킹 포스팅, 쿠팡파트너스 4개 탭만 지원합니다. 홍보발행·리뷰포스팅은 원격 제어가 지원되지 않습니다.

봇 시작 및 메뉴 열기

포스티아가 실행되면 텔레그램 봇으로 "Postia 시작됨" 알림이 자동 전송됩니다. 채팅창에 /start 를 입력하면 원격 제어 메뉴가 열립니다.

발행 완료 알림 및 캡차 대응

글 발행이 완료될 때마다 플랫폼·블로그명과 함께 ✅ 발행 완료 알림이 전송됩니다. 티스토리 캡차가 발생하면 ⚠️ [티스토리 캡차 발생] 메시지와 함께 캡차 이미지가 전송되며, 채팅창에 캡차 텍스트를 입력(300초 이내)하면 자동으로 처리가 재개됩니다.

  • ✍ 키워드 지정: 이번 회차에 사용할 키워드를 직접 지정합니다.

에이전트 탭 원격 제어

  • ▶ 지금 실행: 에이전트를 즉시 실행합니다.
  • ⏹ 중지: 실행 중인 에이전트를 중지합니다.

블로그 활성/비활성 관리

블로그 관리 메뉴에서 등록된 블로그별로 활성/비활성 상태를 확인하고 토글할 수 있습니다. ✅는 활성(발행 대상), ❌는 비활성(발행 제외)을 의미합니다. 각 블로그 옆 [끄기] 버튼을 누르면 즉시 해당 블로그로의 발행이 중단됩니다.

쿠팡파트너스 원격 발행

  • ⚡ 자동 발행: AI가 최적 상품을 자동으로 선택하여 발행합니다.

상품 선택 발행 선택 시 채팅창에 키워드를 입력합니다. (예: 태블릿) 쿠팡 상품 5개가 목록으로 표시되며 원하는 번호 버튼을 누르면 해당 상품으로 리뷰 글이 자동 생성·발행됩니다.

13. 기타 안내

13-1 기기 초기화

라이선스는 최초 인증한 기기에 고정됩니다. PC를 교체하거나 포맷 후 새 기기에서 사용하려면 기기 초기화가 필요합니다.

기기 초기화는 프로그램 내에서 직접 진행하실 수 있습니다. 설정 탭 하단의 기기 초기화 항목에서 버튼을 클릭하시면 됩니다.

① 상단 메뉴에서 설정 탭 클릭

② 스크롤을 내려 하단의 기기 초기화 항목 찾기

③ 기기 초기화 버튼 클릭 → 확인 팝업에서 Yes 선택

④ "초기화 완료" 메시지 확인 후 프로그램 재시작

⑤ 새 기기에서 프로그램 실행 후 동일한 라이선스 키로 재인증

⚠️ 기기 초기화는 현재 등록된 기기에서만 실행할 수 있습니다. 기존 기기에 더 이상 접근할 수 없는 경우(분실, 파손 등)에는 아래 문의처로 연락해 주세요.

자주 묻는 질문

Q. 이미지 생성이 안 됩니다.
A. 설정 탭에서 OpenAI API 키가 등록되어 있는지 확인하고, 🔗 연결 테스트 버튼으로 키가 정상인지 확인하세요. 키는 정상인데 실패한다면 OpenAI 사이트에서 결제 잔액이 남아 있는지, 월 사용 한도에 도달하지 않았는지도 확인해 주세요.

Q. 네이버/티스토리 로그인이 실패합니다.
A. 2단계 인증이 해제되어 있는지 확인하세요. 또한 최근에 비밀번호를 변경하셨다면 프로그램에 등록된 계정 정보도 함께 수정해주세요.

Q. 발행은 완료되었는데 글이 블로그에 보이지 않습니다.
A. 티스토리의 경우 임시저장 설정이 되어 있으면 비공개 상태로 저장됩니다. 티스토리 관리자에서 직접 공개로 전환하세요. 네이버 블로그의 경우 발행 후 검색 노출까지 시간이 걸릴 수 있습니다.

Q. 프로그램을 새 PC에 설치했는데 라이선스 인증이 안 됩니다.
A. 라이선스는 1개 기기에 고정됩니다. 기기 초기화 요청 후 재인증하시면 됩니다. 위 13-1 항목을 참고하세요.
