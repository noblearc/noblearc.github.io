Q.AI 비용이 따로 많이 나가나요?
API 사용료는 이용료와 별도이며, 사용한 만큼만 각 서비스에 청구됩니다. 상품 이미지를 영상으로 전환하는 기능은 무료로 제공해 드립니다.
Q.여러 대의 PC에서 쓸 수 있나요?
라이선스는 1 PC 기준이며, 기기 초기화를 통해 기기를 변경할 수 있습니다.
Q.이용 기간이 끝나면 어떻게 되나요?
라이선스가 만료되어 프로그램을 더 이상 실행할 수 없습니다. 홈페이지에서 재결제하시면 즉시 이어서 이용하실 수 있습니다.
Q.계속 드는 비용이 있나요?
이용권 금액 외에 별도 구독료는 없습니다. 다만 사용하는 AI 서비스 API 요금은 사용한 만큼 각 서비스에 별도로 청구됩니다.
Q.쿠팡파트너스 계정이 꼭 있어야 하나요?
쿠팡파트너스 상품 소싱 기능을 쓰려면 필요합니다. 계정이 없으셔도 보유 중인 상품을 직접 등록하는 "내 상품" 모드로도 제작 가능합니다.
