정밀도의 핵심

신호 찾는 해상도와
체결 확인 해상도를 분리합니다

기준봉(신호)은 15분봉·1시간봉처럼 원하는 타임프레임으로 찾되, 신호가 뜬 다음부터는 진입~청산까지 반드시 1분봉을 처음부터 끝까지 순서대로 재생합니다. 중간을 건너뛰는 하이브리드 판정은 하지 않습니다.

흔한 방식
정밀 백테스트
신호 캔들 안에서 손절·익절을 동시에 낙관 판정
진입 이후 1분봉을 끝까지 순차 재생해서 실제 순서 확인
같은 분 안 동시발생 시 유리한 쪽으로 처리
시가가 이미 넘겼으면 시가로, 아니면 불리한 쪽부터 확인(보수적 우선순위)
그래도 애매하면 그냥 추정해서 넘어감
바이낸스는 실제 체결(tick) 데이터로 한 번 더 대조 검증
지금 기준 상위 종목으로만 전체 기간 계산
그 시점 기준으로 유니버스를 다시 구성하는 옵션 제공

모든 판정 기준은 프로그램 안에서 그대로 확인할 수 있고, 개별 거래 전체(종목·진입일시·청산일시·가격)를 CSV로 내려받아 직접 재검산할 수 있습니다.

사용 경험

코딩 대신, 대화로

조건을 자연어로 설명하면 프로그램이 이해한 내용을 정리해서 보여주고, 정말 필요한 정보가 빠졌을 때만 되묻습니다. 언급하지 않은 값은 임의로 채우지 않습니다.

국내 거래소에서 15분봉 기준으로 거래량이 평균 대비 3배 이상 터지면 매수하고 싶어요.
거래량 "평균"의 기준 기간이 필요해요 — 예를 들어 직전 20봉 평균 대비 3배처럼요. 그리고 손절 기준도 아직 안 주셨는데, 몇 %로 할까요?
직전 20봉 평균, 손절은 5%, 익절은 8%로 해줘.
확인했습니다. 검증 기간은 특별히 없으시면 최근 3년으로, 동시보유 슬롯은 3개로 진행할게요. 이대로 실행할까요?

실제 대화 흐름을 그대로 재현한 예시입니다. 조건이 다 모이면 표로 정리해서 마지막으로 한 번 더 확인시켜 드립니다.

신뢰할 수 있는 이유

데이터도, API 키도
전부 내 컴퓨터 안에만

  • API 키는 이 컴퓨터에만 저장되고, 어디로도 전송되지 않습니다.
  • 조건 해석에만 API를 쓰고, 매매 실행이나 자금 이동은 이 프로그램이 하지 않습니다.
  • 같은 조건으로 다시 실행하면 항상 같은 결과가 나옵니다(재현가능성).
  • 한 번 계산한 숫자를 그대로 믿지 않도록, 스윕·롤링윈도우 같은 재검증 도구를 함께 제공합니다.
  • 이미 받아온 데이터는 캐시에 남겨서, 같은 구간을 다시 검증할 때 처음부터 다시 받지 않습니다.

자주 묻는 질문

이 프로그램이 매매기법을 알려주나요?
아니요. 이 프로그램은 사용자가 직접 설명한 조건을 정확하게 검증해주는 도구입니다. 특정 매매기법을 제공하거나 추천하지 않습니다.
코딩을 전혀 몰라도 쓸 수 있나요?
네. 매매 아이디어를 자연어로 설명하면 자동화 프로그램이 실행 가능한 조건으로 구조화합니다. 정말 필요한 정보가 부족할 때만 대화로 되묻습니다.
Claude API 비용은 어떻게 되나요?
본인의 Claude API 키를 직접 등록해서 사용하며, API 사용료는 본인 부담입니다(조건 해석 단계에서만 소량 사용되며, 백테스트 계산 자체는 API를 쓰지 않습니다).
어떤 거래소를 지원하나요?
국내 거래소 현물, 바이낸스 현물, 바이낸스 USDT-M 무기한 선물(레버리지 포함)을 지원합니다.
수익을 보장하나요?
아니요. 본 프로그램은 과거 데이터를 기반으로 조건을 정밀하게 계산해주는 소프트웨어이며, 특정 수익을 보장하지 않습니다. 백테스트 결과는 미래 수익을 담보하지 않습니다.
실시간 매매 신호나 자동매매를 대신 해주나요?
아니요. 과거 데이터 검증(백테스트) 전용 프로그램이며, 실시간 신호 제공·매매 대행·리딩은 하지 않습니다.
이용 기간은 어떻게 되나요?
월 단위 이용권입니다. 결제 직후 이메일로 안내되는 라이선스 키로 설치·인증하시면 되며, 첫 기기 등록 시점부터 1개월간 이용할 수 있습니다. 기간이 끝나면 홈페이지에서 재결제하여 이어서 이용할 수 있습니다.
PC 사양은 어느 정도면 되나요?
일반적인 사무용 윈도우 PC면 충분합니다. 인터넷 연결과 본인의 API 키만 있으면 됩니다.

법적 고지

※ 본 상품(정밀 백테스트 프로그램 + 사용설명서)은 사용자가 직접 설명한 매매 조건을 과거 데이터로 정밀하게 계산해주는 소프트웨어 도구이며, 특정 매매기법·투자자산·종목을 제공하거나 추천하지 않습니다.

※ 본 프로그램은 백테스트(과거 데이터 검증) 전용이며, 실시간 매매 신호 제공, 매매 대행, 투자 리딩을 일절 하지 않습니다.

※ 조건 해석에 사용되는 Claude API는 구매자 본인의 개인 키로 동작하며, 그 사용료는 구매자 본인 부담입니다.
